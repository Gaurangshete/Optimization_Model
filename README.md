Supply Chain Network Optimization:-
Mixed Integer Linear Programming solution for strategic facility location and distribution routing
Overview:-
This project solves a real-world supply chain optimization problem where a national e-commerce company must decide:

1.Which warehouse locations to open (strategic decision)
2.How to optimally route products from warehouses to customers (tactical decision)

The goal is to minimize total costs (fixed facility costs + variable shipping costs) while satisfying all customer demand and capacity constraints.
